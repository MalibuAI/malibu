# Pricing comparison

> Evidence for buyer-cost claims in the [Litepaper](/litepaper). **Last reviewed:** 16 August 2026.

Savings are **model-specific**. The old 20–40% band is not a uniform guarantee. This page snapshots live Malibu rates against public OpenRouter list prices on the same family.

## Live Malibu pricing

```
GET https://malibu.tech/v1/rate-card
```

Not on the buyer gateway (`api.malibu.tech/v1/rate-card` is 404 by design). Public URL:

```
GET https://malibu.tech/v1/rate-card
```

## How to rerun the comparison

1. Download `https://malibu.tech/v1/rate-card` and record `generated_at`.
2. Download OpenRouter (or another aggregator) list prices with date.
3. Convert Malibu credits: `usd = credits_per_mtok / 1e6 * usd_per_million_credits`.
4. Compare the same token mix. Include `prompt_cache_hit_rate_per_mtok` if your agent replays context.
5. Exclude closed flagship SKUs with no OSS equivalent.

## Default row (no model match)

If a request hits the `default` rate-card row: **$0.50 / $1.00** per 1M prompt/completion — usually **more expensive** than aggregator OSS list. Prefer an explicit priced model.

## When Malibu is not cheaper

- **Cold catalog rows** — price without supply is not a savings.
- **Some 20B–32B SKUs** — this snapshot is flat or slightly above OpenRouter list.
- **Latency / availability** — consumer Mac routing vs dedicated GPU clusters.
- **Confidential compute** — cooperative-trust, not TEE. Economic comparison only.
