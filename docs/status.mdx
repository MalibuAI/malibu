# Network status

> What runs today vs what is planned.

This page is the factual ledger behind the [Litepaper](/litepaper). Narrative copy may mix live and planned features in one arc; this page does not.

**Last reviewed:** 23 September 2026

Status labels: **Live** runs in production for users; a note in parentheses, such as *(partial)* or *(free quota)*, narrows the scope. **Beta** is shipped but limited or experimental. **Preview** is visible but not yet functional for its end use. **Pending** is shipped but not working today until an update lands. **Default-off** is built and shipped in code but disabled in production. **Off** is built and switched off until a stated milestone. **Prototype** is research code that is not integrated into production. **Planned** (optionally with a milestone such as v0) is not built or not released. **Not available** is not offered. See the [Glossary](/network/glossary#status-labels-docs).

| Structured output (`json_schema`) | **Live** | Strict schema subset, validated after generation (not constrained decoding). See [Structured output](/agentic/structured-output) |
| Buyer billing | **Live (free quota)** | Public buyers are not charged money in pre-beta. Each account gets a daily token quota. Card checkout and prepaid top-up are not live. See [Economics](/guides/economics#what-buyers-pay-today) |

## Settlement, credits, and payouts

| Component | Status | Notes |
| --- | --- | --- |
| Verified model settlement | **Live (enforced)** | Only a valid, on-time v0.4 settlement receipt makes a request payable. Missing, invalid, or late receipts settle with zero provider credit and no buyer debit. See [Verified model settlement](/operations/verified-model-settlement) |
| Buyer-visible receipt header | **Live (partial)** | Some non-streaming responses carry a v0.3 receipt in `X-MacProvider-Receipt` (currently roughly a quarter to a third); streams never do. For the rest, use `/v1/receipts`. It never carries the v0.4 settlement receipt. See [Signed receipts](/guides/receipts) |
| Offline receipt verification | **Pending** | Offline verification of current receipts is pending a verifier update. The released verifier cannot parse current receipts. See [Receipt verifier](/cli/malibu-verify) |
| Provider credit share | **Live** | **90%** provider / 10% operator on every rate-card row. See [Economics](/guides/economics) |
| Payout wallet registration | **Live** | Add a payout address in the Malibu dashboard. Registering does not send funds |
| USDC-on-Base payouts | **Off (planned for public beta)** | The payout pipeline is built but switched off. No USDC is paid in pre-beta. See [Payments & payouts](/guides/payments) |
| Off-chain reward ledger | **Preview** | A $MALIBU reward ledger for verified work, shown in the dashboard. Not withdrawable and not a token |
| Wholesale partner traffic | **Live (partners)** | Selected partners send traffic under postpaid invoicing. Not a public buyer option |

## Economics — today vs launch

**Today (pre-beta marketplace):** providers earn **90%** of gross credits; operator retains 10%. Credits accrue on the billing ledger. Public buyers use a free daily quota and are not charged. **USDC-on-Base payout is off** and planned for public beta. Details: [Economics](/guides/economics), [Payments & payouts](/guides/payments).

**At token launch (planned):** buyer USDC splits **70%** provider / **12%** reserves / **18%** market-buy-and-burn. Described in the Litepaper flywheel section; not active in production billing.

## Verification primitives

| Primitive | Status | Proves | Does not prove |
| --- | --- | --- | --- |
| Settlement receipts (v0.4) | **Live** | The provider key signed request, output, and route-snapshot digests, and its reported model hash matched the route-time catalog | Forward-pass fidelity, hardware attestation, private prompts |
| Buyer receipts (v0.3) | **Live (partial)** | The provider key signed prompt hash, output hash, reported model, and timestamp | Same limits; not present on every response. Offline verification pending a verifier update |
| PoMW (memory-hard walk) | **Prototype** | Model residency + memory-substrate rate | Inference equivalence, routing honesty |
| TOPLOC | **Planned v1** | Served completion on attested weights | Pre-buyer readiness |
