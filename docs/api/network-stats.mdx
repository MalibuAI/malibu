# Network stats

> GET /v1/network-stats — public network snapshot.

Public read-only snapshot of the network: pool size, models warm, request rate. No authentication required.

## Endpoint

```
GET https://api.malibu.tech/v1/network-stats
```

## Response

```json theme={null}
{
  "snapshot_ts": "2026-07-03T12:00:00Z",
  "pool": {
    "total": 342,
    "pinned": 47,
    "provisional": 295,
    "warming": 8
  },
  "models_warm": [
    {
      "model_id": "mlx-community/Qwen2.5-7B-Instruct-4bit",
      "provider_count": 128,
      "requests_last_hour": 4021
    },
    {
      "model_id": "mlx-community/Llama-3.2-3B-Instruct-4bit",
      "provider_count": 82,
      "requests_last_hour": 1573
    }
  ],
  "throughput": {
    "requests_last_hour": 8244,
    "tokens_out_last_hour": 12_405_000
  },
  "receipts": {
    "valid_rate_last_24h": 0.9987,
    "receipt_version": "0.3"
  }
}
```

## Fields

| Field                             | Meaning                                                       |
| --------------------------------- | ------------------------------------------------------------- |
| `snapshot_ts`                     | RFC3339 timestamp of this snapshot                            |
| `pool.total`                      | Currently connected providers                                 |
| `pool.pinned`                     | Providers at the pinned tier                                  |
| `pool.provisional`                | Providers at the provisional tier                             |
| `pool.warming`                    | Providers in the post-reconnect warmup gate                   |
| `models_warm[]`                   | Per-model advertised warm counts and last-hour request volume |
| `throughput.requests_last_hour`   | Sum across all models                                         |
| `throughput.tokens_out_last_hour` | Completion tokens in the last hour                            |
| `receipts.valid_rate_last_24h`    | Fraction of receipts that verified `valid` in the last 24h    |
| `receipts.receipt_version`        | Current receipt tuple version                                 |

## Cache

The endpoint is cached at the edge for 30 seconds. Callers polling faster than 30 s see the same snapshot until it refreshes.

## Rate limit

10 requests per minute per source IP. No API key needed.
