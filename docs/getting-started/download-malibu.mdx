# Download Malibu

> Turn any Apple Silicon Mac into a paid AI provider in a few clicks.

The Malibu app is the primary way to join the network as a provider. Signed `.dmg`, menu-bar wrapper around the underlying `malibu-cli` binary. No terminal required.

The app walks you through four steps:

1. **Pick a model.** Malibu detects your Mac's RAM tier and sustained TPS, then recommends an MLX model that fits — Qwen, Llama, or Gemma family. You can override.
2. **Sign in.** GitHub OAuth. This links your Mac to a provider identity you can move between machines.
3. **Start serving.** The app registers with the coordinator over an outbound WebSocket. First request usually arrives within seconds.
4. **Check earnings.** Balance, per-model breakdown, payout status — all in the app. No portal, no dashboard.

## What you get

* **Auto-detected model choice** matched to your Mac's RAM, sustained TPS, and 4K-prompt TTFT.
* **Auto-updates.** When a newer binary ships, the app validates the signed release, drains in-flight requests, and swaps in place.
* **Menu-bar controls.** Pause serving, switch models, view live request rate without leaving the menu bar.
* **Weekly USDC payouts** on Base once you cross the minimum payout threshold. See [Payments & payouts](/guides/payments).

## Requirements

* Apple Silicon Mac (M1 or newer)
* macOS 14 or later
* 16 GB RAM minimum (32 GB+ for larger models)
* Stable network connection (outbound WebSocket to `coordinator.malibu.tech`)

No port-forwarding, no static IP, no incoming firewall rules.
