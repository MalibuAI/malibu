# Changelog

> API field additions, receipt version bumps, and docs semantic changes.

## September 2026

### Buyer API

- **Sticky conversations are live.** Send `X-MacProvider-Conversation: <tag>` to prefer the provider that served earlier turns, for up to 1,800 seconds. It is a preference, not a guarantee, and often routes elsewhere; only sticky hits bill at the cache-hit rate. `DELETE /v1/sticky` clears your sticky state. The live posture is in `tier1_disclosure.sticky_affinity` on `GET /v1/models`
- Automatic prefix-cache reuse for OpenAI-compatible clients: repeated system prompts and tool scaffolds can reuse a Mac's KV cache without any header. These hits are reported in the OpenAI-standard `usage.prompt_tokens_details.cached_tokens` and billed at the full prompt rate
- Tool calling: tool-call IDs from other OpenAI-compatible clients are accepted and rewritten; `tool_choice: "required"` or a named function is served as `auto`; streamed tool calls are safe to concatenate
- Next provider release (not in stable v1.8.123): removal of the 256-message cap on chat requests (stable providers still return `400 messages_too_long` above 256 messages), and recovery of incomplete Qwen XML tool-call wrappers and leftover tool markup instead of failing the stream
- Routing skips providers below a minimum throughput floor, and seat accounting no longer hides free seats when a Mac reports "busy" late
- Settlement robustness: a served completion is returned to the buyer even if recording its settlement evidence hits a database deadline, and settlement holds are reconciled promptly
- New reference pages for the **Beta** OpenAI Responses facade (`POST /v1/responses`) and the experimental Anthropic Messages facade (`POST /v1/messages`)

### Models and pricing

- The signed model catalog was re-signed on 23 Sep 2026 to cover **17 models**, and it is live. Stable provider v1.8.123 fetches the live 17-row feed and falls back to its compiled-in 10 rows if the fetch, signature, or age check fails. See [Model catalog](/operations/model-catalog)
- Seven new priced rate-card rows: Qwen3 30B A3B Instruct 2507, GLM-4.5-Air, Qwen3.5 27B, Qwen3.5 35B A3B, Qwen3.6 27B, Qwen3.6 35B A3B and Qwen3.8 27B
- gpt-oss-120b joined the autotune catalog for 90 GB+ Macs
- The rate card is now a signed feed derived from a dated market snapshot, with a guard that stops the signed rates and the billing configuration from drifting apart
- Corrected the Qwen3.6 27B catalog artifact identity so providers serving it match the signed row. Parts of this fix are provider-side and ship in the next provider release

### Documentation

A full refresh against the shipped system on 23 Sep 2026. Corrections:

- **Header names.** There are no `X-Malibu-*` headers. Real ones include `X-MacProvider-Conversation` and `Idempotency-Key` (request) and `X-Provider-Id`, `X-Request-ID`, `X-RateLimit-*`, `Retry-After`, `X-MacProvider-Receipt` and `X-MacProvider-Streaming-Mode` (response). See [Headers](/api/headers) for the full list
- **Receipt verifier.** The tool is `macprovider-verify` (release `verify-v1.1.0`); `malibu-verify` never existed. Offline verification of current receipts is pending a verifier update: 1.1.0 cannot parse today's v0.3 buyer receipts. Settlement receipts (v0.4) are checked by the network and are never sent to buyers. Some non-streaming responses carry a v0.3 receipt header (currently roughly a quarter to a third); streams never do. For the rest, use `/v1/receipts`
- **Provider CLI.** Config lives at `~/.config/macprovider/config.yaml`, environment variables use the `MACPROVIDER_` prefix, and the LaunchAgent label is `live.malibu.provider`. Invented flags, commands, env vars and `~/.malibu` paths were removed
- **Autoupdate.** Releases are checked with an ECDSA P-256 signature over `checksums.txt`, not Ed25519. Nonexistent `channel`, `drain_timeout_s` and `autoupdate rollback` options were removed; manual recovery is `recover-update`
- **Structured output** is validated after generation, not enforced by constrained decoding
- **Pinning.** Buyers cannot pin a request to a provider; sticky conversations are the supported way to prefer one
- **Cache billing.** Only sticky-conversation hits bill at the cache-hit rate; automatic prefix-cache hits bill at the full prompt rate
- **Settlement.** Outcomes are `verified`, `pending`, `quarantined` and `zero_settled`, with a 300-second pending deadline
- **Model catalog.** The 17-model signed catalog with per-model memory floors replaces older lists. Qwen2.5 7B and Llama 3.3 70B are not in the catalog
- **Money.** Public buyers are not charged in pre-beta (daily token quota); USDC payouts are off; wallet registration only records an address
- **Routing tiers.** New Macs move from provisional to trusted by meeting trust criteria; pinned is set only in operator configuration
- **Litepaper.** Removed per-Mac annual dollar figures and hardware-payback lines, and labeled the PoMW prototype numbers as unaudited
- New pages: [Trust disclosure](/network/trust-disclosure), [Responses](/api/responses), [Messages](/api/messages)
