# Changelog

> API field additions, receipt version bumps, and docs semantic changes.

## August 2026

### Product (docs catch-up)

- Public snapshot is `GET https://malibu.tech/v1/stats/overview` (coordinator/stats origin). `api.malibu.tech/v1/network-stats` is 404 **by design** — buyer gateway does not mount that path
- Public rate card is `GET https://malibu.tech/v1/rate-card` (coordinator origin). Gateway `/v1/rate-card` is the same kind of 404
- `GET /v1/models` requires a Bearer token
- Provider admission is **invite-gated pre-beta** ([malibu.tech/host](https://malibu.tech/host)); fresh register needs `malibu.tech/j#/…`
- Download pin follows GitHub Latest (accepted Malibu app **v1.8.93** as of 16 Aug 2026)
- Console: agent tools, stop control, activity bus, client-measured decode tok/s on the bill line
- Catalog vs warm set: Qwen2.5 7B, Qwen3.5 35B, Llama 3.3 70B, gpt-oss 120B stay **catalog-eligible** (route when matching-RAM Macs join). Warm snapshot on 16 Aug 2026 was 3B + Qwen3-8B
- Homepage and `/host` earn copy matches the ledger: USDC 90/10 live; $MALIBU / 70/12/18 planned
- Operating entity named on site: Superposition Technologies Pte. Ltd. ([company](https://malibu.tech/company), [privacy](https://malibu.tech/privacy), [terms](https://malibu.tech/terms))
